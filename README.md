# Estudos Bíblicos - Família Miranda

O objetivo principal deste repositório é armazenar de forma sistemática estudos bíblicos ministrados durante o culto doméstico da família Miranda. O armazenamento organizado destas reflexões permitirá consulta posterior e poderá servir de ajuda inicial àqueles que desejam de iniciar uma rotina de culto doméstico em seus lares.
